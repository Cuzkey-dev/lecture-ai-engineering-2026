# 第1回 解答

## 演習

- 講座に固有の質問（宿題の3レベル）へのモデルの回答（要約でよい）：「受講しているコースによって意味が異なる」と前置きしたうえで、「基礎・応用・発展」「AI活用の階層」「思考の深さ（Bloomのタクソノミー）」など、一般論の3段階を複数並べた。最後に講座のポータルやSlackで確認するよう勧めていた。
- 用語集の正しい意味と比べて気づいたこと：正解は「基礎（講義内容の確認）・実装（自分でコードを書く）・発展（調査や試行）の3段階で、どれか1つに取り組めば完了」。モデルは「分からない」とは言わず、もっともらしい一般論を出した。「実装」という段階名も、「どれか1つで完了」という条件も出てこなかった。
- 表示できたトークン数（入力 / 出力）：「LoRAとは何ですか？」は 7 / 719、「宿題の3レベル」の質問は 21 / 723（gemini-3.5-flash-lite・既定設定）。

## 宿題

- 取り組んだレベル：基礎
- やったこと：
  - `app/ask.py` に `--temperature` オプションを足し、`generate_content` の `config`（`types.GenerateContentConfig`）で temperature を渡せるようにした。
  - `scripts/lec01_basic.py` を作り、2つの質問（「LoRAとは何ですか？」「AIE2026の講座の宿題にある「3レベル」とは何ですか？」）を、次の4条件で3回ずつ実行した（計24回）。全回答・応答時間・トークン数は `lectures/01/basic_runs.md` にある。
    1. gemini-3.5-flash-lite・temperature 既定
    2. gemini-3.5-flash-lite・temperature 0.0
    3. gemini-3.5-flash-lite・temperature 1.5
    4. gemini-3.5-flash・temperature 既定
- 結果：

| 条件 | LoRA：出力トークン（3回） | 3レベル：出力トークン（3回） | 応答時間 |
|---|---|---|---|
| flash-lite・既定 | 782 / 610 / 472 | 691 / 606 / 571 | 2.4〜3.7秒 |
| flash-lite・0.0 | 538 / 578 / 505 | 585 / 416 / 424 | 2.4〜2.9秒 |
| flash-lite・1.5 | 565 / 652 / 613 | 396 / 583 / 451 | 2.2〜3.3秒 |
| flash・既定 | 763 / 643 / 699 | 638 / 607 / 607 | 10.4〜13.9秒 |

  - temperature 0.0 でも、3回の回答は一字一句同じにはならなかった（見出し構成も長さも変わった）。
  - 3レベルの質問には24回中どの回も正解（基礎・実装・発展、どれか1つで完了）を答えなかった。flash-lite は「一般的には」と断ったうえで候補を並べ、確認を勧める書き方が多かった。flash は3回とも「レベル1（基礎）は必須・合格ライン、レベル3は挑戦」のように、講座の実態（どれか1つで完了）と違う条件を言い切った。
  - LoRA の質問は、どの条件でも「元の重みを固定して小さな追加行列だけ学習する」という中身はそろっていた。違いは例え話や見出しの立て方だった。
  - flash は flash-lite より応答が約4倍遅かった。
- 気づき・疑問：
  - temperature を 0 にしても出力が固定されないので、「同じ入力なら同じ出力」を前提にした評価やテストは組めない。比べるなら複数回の傾向で見る必要がある。
  - 上位のモデル（flash）の方が、講座固有の質問に自信を持って誤った条件を答えた。知らないことへの答え方は、モデルを大きくしても良くなるとは限らない。用語集のような根拠を渡す仕組み（第3回）が要る理由が分かった。
  - temperature 1.5 は既定値より回答のばらつきが大きくなると予想したが、トークン数でも中身でも、はっきりした差は見えなかった。
